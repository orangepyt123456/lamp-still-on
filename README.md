# 灯还亮着

一个关于中央红色交通线的交互网页。场景放在永定：墙上的标语谁都能看，路条要对上接头信号，伯公灯亮着，香灰下的字才留在外面。

你不是指挥官。你只知道下一站。

## 页面里有什么

- **墙**：虎岗留存标语「打通闽粤赣交通路线，革命成功」，以及高陂锡光堂没认清的两个字。看不清的字标红，不补写。
- **路条**：用交通线上的水路信号做示意核验。「江面无风」放行，「江面起风」站口不应答。持有人留白，因为许多交通员没有留下姓名。
- **伯公灯**：灯亮表示安全，灯灭表示危险。情报藏在灯前香灰下。灯灭以后，纸条收回去。
- **知识图谱**：点一个词，或点右边的节点，看这一夜怎样连在一起。
- **交通员**：左下角的三维人物会开口。他没有名字，也没有穿军装。嘴里的话都有出处；没有出处的句子，他不把它念成史料。

墙、路条和人物都是示意，不是档案原件照片。

## 本地打开

在这个目录执行：

```
python -m http.server 4173
```

浏览器打开 http://127.0.0.1:4173/

三维人物使用 [Three.js](https://github.com/mrdoob/three.js)（MIT）。语音使用浏览器自带的中文语音；没有语音时，字幕仍然显示。
